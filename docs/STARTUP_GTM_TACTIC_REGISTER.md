# Sovereign Source GTM tactic register

**Planning date: 12 October 2026.** Companion to the [startup go-to-market plan](STARTUP_GO_TO_MARKET_PLAN.md).

This register screens 139 tactics from the marketing planning catalog. Each appears once with a primary funnel stage; some can serve multiple stages. Names are catalog labels, not claims that these tactics are proven for Sovereign Source or that referenced platforms remain available.

**Now** supports the first 90 days within the plan's three channels, including preparing assets whose public use requires implementation. **Q2**, **Q3+** and **Q4+** refer to relative planning quarters and remain conditional on budget, capacity and the row's prerequisites. **Skip** means excluded from this plan, not a universal judgment about the tactic. Proposed outreach, posts, events and spending require separate execution; publishing this register performs none of them.

**Screening totals:** 14 Now; 28 Q2; 32 Q3+; 12 Q4+; 53 Skip. These are options, not a workload or hiring commitment.
